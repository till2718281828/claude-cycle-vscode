# Демо: СтальКонструкт-Демо

Семь вымышленных проектов, на которых монитор «Цикл-Про» работает сразу после установки — без настроек.
Компания, люди и числа выдуманы. В демо «сегодня» закреплено на **16.11.2026** (`_активность.json`), поэтому
сроки и «без движения» не устаревают со временем.

- `_настройки.json` — настройки монитора, как их задал бы пользователь: лимит P1 = 3, личный проект, конвейер периода.
- `_сервер.json` — состояние вымышленного сервера для плитки сервера (commit 87 % и ожидание перезагрузки — жёлтая плитка).
- `_активность.json` — активность и даты движения планов. В демо нет `.git`, поэтому коммиты, сессии
  и «незакоммичено» берутся отсюда; у своей папки проектов сборщик читает git и сессии Claude Code.
