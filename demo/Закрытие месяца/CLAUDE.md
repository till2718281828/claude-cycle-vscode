# Закрытие месяца

Ежемесячное закрытие СтальКонструкт-Демо: выгрузки из учётной системы, расчёт, отчёт.

## Цикл

```yaml
профиль: A
планы: _Служебное/Планы
журнал: _Служебное/Журнал решений.md
бэклог: _Служебное/Бэклог.md
выгрузки: Выгрузки/{период}
ожидаемые: оборотка*.csv, склад*.csv, зарплата*.csv
```
