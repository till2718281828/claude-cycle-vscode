# Цикл работы

**Когда нужен цикл:** меняются числа выпуска, затронуто больше двух файлов или результат уходит наружу.
Иначе — просто попросите Claude, без плана. **Продолжить начатое:** откройте проект — строка статуса покажет
открытый план и шаг; напишите «продолжай».

## Команды цикла

| # | Фаза | Команда | Что делает |
|---|---|---|---|
| 1 | Разведка | `Shift+Tab` | plan mode — до утверждения плана файлы не меняются |
| 2 | Grill | `/grill-me` · `/grilling` | вопросы раундами, к каждому рекомендация; `/grill-with-docs` — со словарём терминов и ADR |
| 3 | План | `/plan-task` | план по шаблону в `_Служебное/Планы/` проекта |
| 4 | Исполнение | `/execute` | шаг → проверка критерия → галочка → коммит; остановка на СТОП; «продолжай» |
|  | внутри исполнения | `/tdd` | тесты сначала, по согласованным точкам |
|  | внутри исполнения | `/cycle:code-review` | ревью кода: стандарты и соответствие плану |
| 5 | Проверка | `/cycle:verify` | независимый проверяющий с чистым контекстом |
| 6 | Закрытие | `/close-task` | журнал решений, «Ловушки», статус «закрыт» |

## Профили проектов

A — выпуск по периоду (Excel, презентации) · B — код-инструмент · C — документ. Профиль и пути — в блоке «Цикл»
файла `CLAUDE.md` проекта. Нет блока — `/cycle-setup`.
