# Цикл работы

| # | Фаза | Как |
|---|---|---|
| 1 | Разведка | включить **plan mode** (Shift+Tab) — до утверждения плана файлы не меняются |
| 2 | Grill | `/grill-me <задача>` — вопросы раундами, к каждому рекомендация |
| 3 | План | `/plan-task` — план ложится в `_Служебное/Планы/` проекта |
| 4 | Исполнение | утвердить план → `/execute`: шаг → проверка критерия → галочка → коммит; остановка на СТОП |
| 5 | Проверка | `/verify` — независимый проверяющий с чистым контекстом |
| 6 | Закрытие | `/close-task` — журнал решений, «Ловушки», статус «закрыт» |

**Когда нужен цикл:** меняются числа выпуска, затронуто больше двух файлов или результат уходит наружу.
Иначе — просто попросите Claude, без плана.

**Профили проектов:** A — выпуск по периоду (Excel, презентации) · B — код-инструмент · C — документ.
Профиль и пути — в блоке «Цикл» файла `CLAUDE.md` проекта. Нет блока — `/cycle-setup`.

**Продолжить начатое:** откройте проект — строка статуса покажет открытый план и шаг; напишите «продолжай».
