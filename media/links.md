# Пульт и документы

- **Пульт** — HTML-страница статуса задач по всем проектам. Ссылка появится, когда в настройке
  `cycleWelcome.projectsRoot` указана папка, где лежит `пульт.html`.
- **Карта репозиториев** — встроенный демо-пример: какой репозиторий что хранит и кому отдаёт.
- **Свои документы** — README плагина, план цикла, своя карта и что угодно ещё: добавьте их в настройку
  `cycleWelcome.links`, и ссылки появятся здесь.

```json
"cycleWelcome.links": [
  { "title": "README плагина", "path": "C:/Projects/plugin/README.md" },
  { "title": "План цикла", "path": "docs/план-цикла.md" }
]
```

Относительный путь считается от папки проектов (`cycleWelcome.projectsRoot`). Markdown открывается в предпросмотре.

Отключить автопоказ памятки: настройка `cycleWelcome.showOnStartup`. Открыть вручную: команда **«Цикл: памятка»**.
