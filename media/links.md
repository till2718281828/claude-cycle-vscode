# Монитор и документы

- **Монитор проектов** — первый раздел вкладки. Без настроек показывает встроенное демо СтальКонструкт-Демо;
  свою папку проектов укажите в настройке `cycleWelcome.projectsRoot`. Нужен Python 3.10+
  (`cycleWelcome.pythonPath`, если он не в PATH). «Монитор в браузере» — та же страница отдельным HTML.
- **Кнопки монитора** открывают вкладку Claude Code с набранным запросом или терминал в папке проекта — Enter за вами.
  Общие кнопки — `пульт/команды.json` расширения, свои у проекта — `<проект>/_Служебное/команды.json`.
- **Карта репозиториев** — встроенный пример: какой репозиторий что хранит и кому отдаёт.
- **Свои документы** — README плагина, своя карта и что угодно ещё: добавьте их в настройку `cycleWelcome.links`,
  и ссылки появятся здесь.

```json
"cycleWelcome.links": [
  { "title": "README плагина", "path": "/home/me/plugin/README.md" },
  { "title": "План цикла", "path": "docs/план-цикла.md" }
]
```

Относительный путь считается от папки проектов (`cycleWelcome.projectsRoot`). Markdown открывается в предпросмотре.

Отключить автопоказ вкладки: настройка `cycleWelcome.showOnStartup`. Открыть вручную: команда **«Цикл-Про: открыть»**.
