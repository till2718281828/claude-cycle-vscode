# Пульт и документы

- **Пульт** — `пульт.html` в папке проектов: требует внимания, задачи по срокам, без движения, статус проектов.
  Открывается в браузере; пересобирается в конце каждой сессии Claude Code.
- **README плагина** — `_цикл/README.md` в папке проектов: состав, установка, обновление.
- **План цикла** — все решения по процессу с обоснованием.

Отключить автопоказ памятки: настройка `cycleWelcome.showOnStartup`. Открыть вручную: команда **«Цикл: памятка»**.
