## Клавиши и правила

| | |
|---|---|
| **Plan mode** | Shift+Tab или переключатель под полем ввода Claude; пока он включён, Claude только читает |
| **Замечания к плану** | комментируйте строки плана в редакторе, затем **Send feedback and keep planning** — комментарии уйдут разом; **Yes** утверждает план, неотправленные комментарии теряются; план не открылся — `/plan open` |
| **Утверждение плана** | «Yes, auto» — без вопросов до СТОП · «manually approve edits» — подтверждать правки · «очистить контекст» — исполнение с чистого листа |
| **Схема в плане** | рисуется сама при 4+ шагах, зависимостях или СТОП; смотреть — Ctrl+Shift+V; «без схемы» / «добавь схему» |
| **Ход исполнения** | Git Graph: коммит на каждый шаг плана |
| **СТОП в плане** | Claude остановится и скажет, что нужно от вас · «продолжай» = `/execute` по открытому плану |
| **Хуки плагина блокируют** | запись в `.env` и ключи · `push` (кроме `push: разрешён`) · `reset --hard`, `clean -f`, `branch -D`, `checkout .`, `restore .` |
