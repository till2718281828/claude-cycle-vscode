# Клавиши и правила

**Plan mode** — Shift+Tab или переключатель под полем ввода Claude. Пока он включён, Claude только читает.

**Замечания к плану** — комментируйте строки плана в редакторе, затем **Send feedback and keep planning**:
все комментарии уйдут разом, план поправится за один проход. Кнопка **Yes** утверждает план — неотправленные
комментарии при этом теряются. Документ плана не открылся — `/plan open`.

**Схема в плане** — Claude рисует её сам, если шагов больше 4, есть зависимости или СТОП. Смотреть — Ctrl+Shift+V
(предпросмотр Markdown). Не нужна — комментарий «без схемы»; нужна в коротком плане — «добавь схему».
**Ход исполнения** — Git Graph (кнопка на панели Source Control): коммит на каждый шаг плана.

**Утверждение плана:** «Yes, auto» — дальше без вопросов до СТОП · «manually approve edits» — подтверждать правки ·
«очистить контекст» — исполнение начнётся с чистого листа по файлу плана.

**Хуки плагина блокируют:** запись в `.env` и файлы ключей · отправку `push` (кроме проектов с `push: разрешён`) ·
жёсткий сброс (`reset --hard`), `clean -f`, `branch -D`, `checkout .`, `restore .`.

**«продолжай»** = `/execute` по открытому плану · **СТОП в плане** — Claude остановится и скажет, что нужно от вас.
