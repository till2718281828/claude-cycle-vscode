# Команды вне цикла

Команды цикла задачи — на странице «Цикл работы». Команды плагина цикла можно набрать полностью: `/cycle:<имя>`;
без плагина они не работают — Claude Code ответит, что такой команды нет.

## Обзор и учёт

| Команда | Где | Что делает |
|---|---|---|
| `/weekly-review` | все проекты | недельный обзор: приоритеты, сроки, застрявшее |
| `/backlog <текст> [P1-3] [срок]` | любой проект | строка в бэклог проекта |
| `/cycle-setup` | новый проект | подключить проект к циклу (git, настройки, блок «Цикл») |

## Поиск и разбор

| Команда | Где | Что делает |
|---|---|---|
| `/research` | любой | исследование по первоисточникам в Markdown-файл |
| `/diagnosing-bugs` | код | разбор трудной ошибки или замедления |
| `/to-questionnaire` | любой | анкета для человека, который должен принять решение |
| `/retro` | любой | что улучшить в окружении по итогам сессии |

## Диаграммы

Отдельный плагин [diagram-design](https://github.com/cathrynlavery/diagram-design) (MIT): диаграмма — один HTML с SVG,
открывается без сети; 45 типов — блок-схема, Gantt, Sankey, sequence, матрицы и др. Просто попросите словами
(«нарисуй Gantt по плану…») — скилл подключится сам. Исходник не текстовый: схемы, которые часто правятся в git,
удобнее держать в Mermaid.

| Команда | Где | Что делает |
|---|---|---|
| `/diagram-design:import-mermaid` | любой | перерисовать Mermaid (файл `.mmd` или блок в Markdown) в стиле скилла |
| `/diagram-design:import-drawio` | любой | перерисовать файл `.drawio`; исходник не меняется |
| `/diagram-design:import-excalidraw` | любой | перерисовать доску `.excalidraw` |
| `/diagram-design:export-diagram` | любой | PNG и SVG рядом с HTML — для слайдов и docx (нужен Playwright с браузером) |
| `/diagram-design:profile` | любой | сохранить фирменный стиль (палитра, шрифты) и рисовать в нём |
| `/diagram-design:doctor` | любой | проверить окружение скилла |

## Claude Code

| Команда | Где | Что делает |
|---|---|---|
| `/compact` · `/clear` | сессия | сжать контекст длинной сессии · начать с чистого контекста |
| `/resume` · `/rewind` | сессия | продолжить прошлую сессию · откатить сессию и файлы к прошлой точке |
| `/model` · `/fast` | сессия | сменить модель · быстрый режим вывода |
| `/agents` | сессия | субагенты: список, создание |
| `/code-review` · `/simplify` | код | поиск ошибок в изменениях · упростить изменённый код |
| `/loop` · `/schedule` | автоматизация | повторять по интервалу в сессии · агенты в облаке по расписанию |
| `/chrome` | браузер | подключить Claude in Chrome |
