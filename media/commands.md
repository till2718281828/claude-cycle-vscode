# Команды

| Команда | Что делает |
|---|---|
| `/grill-me` · `/grilling` | интервью по развилкам задачи до плана; `/grilling` — вопросы формой, вызывается и фразой |
| `/plan-task` | план по шаблону в папку планов проекта |
| `/execute` | исполнение плана по шагам с коммитом на шаг («продолжай») |
| `/verify` | независимая проверка результата по профилю проекта |
| `/close-task` | закрытие: журнал, уроки на утверждение, статус |
| `/cycle-setup` | подключить проект к циклу (git, настройки, блок «Цикл») |
| `/backlog <текст> [P1-3] [срок]` | строка в бэклог проекта |
| `/weekly-review` | недельный обзор: приоритеты, сроки, застрявшее |
| `/tdd` | тесты сначала, по согласованным точкам |
| `/cycle:code-review` | ревью кода: стандарты + соответствие плану |
| `/retro` | что улучшить в окружении по итогам сессии |
| `/research` | исследование по первоисточникам в Markdown-файл |
| `/diagnosing-bugs` | разбор трудной ошибки или замедления |
| `/to-questionnaire` | анкета для человека, который должен принять решение |
| `/grill-with-docs` | grill + словарь терминов и записи решений (ADR) |

Все команды плагина можно набрать и полностью: `/cycle:<имя>`.

| `/loop` | Claude Code · попробовать | повторять команду по интервалу в сессии |
| `/schedule` | Claude Code · попробовать | агенты в облаке по расписанию |
| `/fast` | Claude Code · попробовать | быстрый режим вывода |
| `/rewind` | Claude Code · попробовать | откат сессии и файлов к прошлой точке |
| `/resume` | Claude Code · попробовать | продолжить прошлую сессию |
