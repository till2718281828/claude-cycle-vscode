# Контракт сводки пульта: `пульт-сводка.json`

Раздел «Требует внимания» читает файл `пульт-сводка.json` из папки, указанной в настройке
`cycleWelcome.projectsRoot`. Файл пишет внешний сборщик: скрипт, который обходит проекты и их планы.
Расширение файл только читает и ничего в нём не считает: что считать просроченным и что «без движения»,
решает сборщик.

- Файла нет или папка не задана — показывается демо на вымышленных проектах.
- Файл есть, но JSON сломан, нет обязательного поля или обязательный счётчик не число — вместо раздела выводится
  текст ошибки. Тексты из сводки показываются как текст: разметка Markdown и HTML в них не срабатывает.

Кодировка UTF-8, ключи по-русски, как ниже.

## Поля верхнего уровня

| Поле | Тип | Обязательно | Как показывается |
|---|---|---|---|
| `требует_внимания` | число | да | заголовок: «Требует внимания: N» — задачи плюс сигналы |
| `просрочено` | число | да | счётчик «Просрочено» |
| `ждёт_вас` | число | да | счётчик «ждёт вас» — задачи на остановке до решения человека |
| `в_работе` | число | да | счётчик «в работе» |
| `бэклог` | число | да | счётчик «в бэклоге» |
| `задачи` | массив | да | таблица «Проект · Задача · Почему»; сборщик кладёт первые несколько по важности |
| `P1_в_работе` | число | нет | показывается только вместе с `лимит_P1` и только если P1 больше лимита |
| `лимит_P1` | число | нет | сколько задач P1 допустимо одновременно |
| `сигналы` | массив | нет | список «Сигналы автоматов» над таблицей |
| `проектов_с_циклом` | число | нет | подвал: «Проектов с циклом: N из M» |
| `проектов` | число | нет | там же, M |
| `собран` | строка | нет | подвал: «Пульт собран …» — дата и время сборки |

Другие поля, например `пульт` (путь к HTML-пульту), расширение пропускает.

## Элемент `задачи`

| Поле | Тип | Как показывается |
|---|---|---|
| `проект` | строка | колонка «Проект» |
| `задача` | строка | колонка «Задача» |
| `приоритет` | строка (`P1`–`P3`) или null | в скобках после задачи |
| `причины` | массив строк | колонка «Почему», через «; » |
| `статус`, `срок` | строка | не показываются: в сводке они для других потребителей |

## Элемент `сигналы`

Сигнал — сообщение автомата проекта: ночной выгрузки, почтового сборщика и т. п.

| Поле | Тип | Как показывается |
|---|---|---|
| `уровень` | `crit` · `warn` · `ok` | «сбой» · «внимание» · «норма» |
| `проект` | строка | перед текстом |
| `текст` | строка | сам сигнал |
| `дата` | строка `ГГГГ-ММ-ДД` | в скобках, если есть |

## Пример

```json
{
 "собран": "2026-10-09 18:40",
 "требует_внимания": 2,
 "просрочено": 1, "ждёт_вас": 1, "в_работе": 3, "бэклог": 7,
 "P1_в_работе": 2, "лимит_P1": 3,
 "проектов_с_циклом": 2, "проектов": 3,
 "сигналы": [{"проект": "Закупки", "текст": "ночная выгрузка не пришла", "уровень": "crit", "дата": "2026-10-09"}],
 "задачи": [{"проект": "Казначейство", "задача": "Платёжный календарь", "статус": "в работе",
             "приоритет": "P1", "срок": "2026-10-08", "причины": ["просрочено на 1 дн."]}]
}
```
